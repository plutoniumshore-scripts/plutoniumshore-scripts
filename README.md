# Plutoniumshore Scripts

A collection of scripts, utilities, and projects built to solve practical problems across Windows, Microsoft 365, networking, home labs, and media management.

Most of these started as tools created for a specific need and were cleaned up, documented, and shared in case someone else finds them useful.

**Why publish them? Sharing is caring.**

## About

I work primarily in infrastructure and systems administration, with a focus on Windows, PowerShell, Microsoft 365, identity and access management, automation, cloud services, and enterprise infrastructure.

PowerShell has been a regular part of that work for years, particularly for administration, reporting, troubleshooting, automation, and turning repetitive operational tasks into reusable tools.

Outside of work, I spend a lot of time with home lab infrastructure, self hosted services, networking, media systems, and other projects that usually begin with, "There has to be a better way to do this."

## Repositories

### [MediaStack Control Gateway](https://github.com/plutoniumshore-scripts/MediaStack-Control-Gateway)

A Windows based MCP gateway for visibility, reporting, and administration across Plex, Tautulli, Sonarr, Radarr, and Lidarr.

**Project status (October 2026):** I've stepped away from active development of MediaStack Control Gateway for the time being, but I'm more than happy to answer questions about it. I'm looking forward to my next project.

### [Microsoft Teams Membership Audit](https://github.com/plutoniumshore-scripts/Microsoft-Teams-Membership-Audit)

A PowerShell utility for auditing and exporting the Microsoft Teams memberships of a specified Microsoft 365 user through Microsoft Graph.

### [Scripts](https://github.com/plutoniumshore-scripts/Scripts)

A collection of standalone PowerShell utilities covering Windows administration, networking, DNS, SMB, file management, troubleshooting, and other practical tasks.
